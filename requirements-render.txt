# Free-tier API image dependencies (Render free instance: 512 MB RAM, 0.1 CPU).
#
# Same application dependencies as requirements.txt with one deliberate
# substitution: the embedding model runs on ONNX Runtime (fastembed) instead of
# PyTorch. torch plus the fp32 multilingual-e5-small checkpoint needs ~1-2 GB
# resident, which a 512 MB instance does not have, and installing torch also
# costs ~200 MB of image for a dependency this image never uses.
#
# Select the backend with EMBEDDING_BACKEND=fastembed (see app/config.py) and
# embed the corpus with the SAME backend — the two runtimes are numerically
# close but not bit-identical, so a corpus embedded with torch and queried
# through ONNX would be scored in a slightly different vector space.
#
# The cross-encoder reranker (BAAI/bge-reranker-base, ~2 GB) is not installable
# here: keep ENABLE_RERANKER=false, which is the default.
